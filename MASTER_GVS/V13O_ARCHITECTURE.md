# GVS v13O — Physical Reasoning Fabric

**Status: architecture/model pass; physical synapse/pressure-cell and AI-scale learning open.**

v13O keeps the accepted v13A/v13K/v13L hardware and changes the hard-question strategy. Instead of `hard -> exact computer`, it tests whether hard work can be decomposed into physically embodied reasoning modes.

## Core mechanisms
1. **Constraint Membrane Fabric:** recurrent membrane states plus local constraint pressure, fatigue and homeostasis search for a stable satisfying attractor without a central solver selecting state changes.
2. **Relation Wavefront:** typed events travel through stored relations, making connectivity itself the traversal engine.
3. **Morphological Exact Patch:** repeated exact operations live as fixed spatial dataflow instead of runtime instructions.
4. Existing Grammar/templates/Myelin/context/competition remain the local perception, memory and routing substrate.

## Selected principle
The device/connectivity should increasingly combine **state + computation + routing + adaptation**. The next bottleneck is not arithmetic; it is cheap learned relation storage and dynamic binding. If every learned relation requires SRAM fetch or an expensive programmable switch, the computer has merely been renamed.

## Current evidence
- adaptive CMF: 62% single-fabric success on held-out 64-variable planted 3-SAT versus 8% plain recurrence; pressure pulse reaches 84%; 16 independent replicas reach 98%;
- relation wavefront: 100% grounded-target recall on tested 2/4/8-hop sparse typed graph queries while activating a tiny fraction of full-scan edges;
- exact patch: exhaustive 65,536/65,536 correct 8-bit additions in 72 NAND cells with no runtime instruction fetch.

## Physical status
A legal 2x2 um MIM pressure-capacitor precheck reached 0 DRC and Magic recognized the MIM device, but the first standalone terminal route was not correctly connected to the extracted top plate. The attempted transistor transient also hit ngspice-26/current-SKY130-model compatibility before evaluating the circuit. These are preserved as open physical work; no generic MOS substitute is called SKY130 proof.

## Next architecture problem
Create a cheap **plastic relation/synapse cell** in which stored relation strength, local computation and adaptation live together. Then test a unified fabric on associative recall, compositional/role binding, relation reasoning, constraint solving, temporal context and exact patches. If it behaves only as several accelerators, change representation rather than adding a CPU fallback.
