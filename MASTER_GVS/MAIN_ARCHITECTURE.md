# GVS / Neural Glyph — MAIN ARCHITECTURE

**Status:** authoritative combined architecture through v13K. Update after every architecture-changing experiment. Version folders preserve evidence and failures; this file states the current integrated system.

## 0. Objective and core rules
Build the cheapest practical hybrid AI hardware that can remain highly capable while reducing unnecessary data movement, repeated memory reads, duplicated routing and conversion overhead.

Core rules:
- stable/reused/local structure -> physical implementation when total cost wins;
- changing/rare/exact state -> exact computer hardware;
- ambiguity/failure -> exact fallback;
- weak analog state stays local/short;
- robust meaning/results may travel farther;
- locality is part of computation;
- raw/noisy activity may not refresh leases or train persistent routes;
- live charge = information; controlled leak = time/adaptation; expired charge may be recovered;
- never load a live high-impedance state merely to harvest it;
- sharing is accepted only when it does not corrupt local decisions;
- DRC alone is insufficient; extracted connectivity/parasitics are authoritative;
- a bad implementation does not automatically reject the principle;
- future-process/package models must never be labelled as fabricated SKY130 measurements.

## 1. Whole-system flow
```text
input / sensor / exact data
        -> Active-Low Coordinate Release
        -> 8-way Regional Event Lease
        -> local intelligent Glyph region
             Tri-Wall capacitive evidence
             shared/static templates
             Grammar motifs
             short Passive Myelin
             local competition/inhibition
             familiarity/context/fatigue/homeostasis
             direct fourth-face neighbor links
             Autonomic Event Spine / subwire taps
        -> confident local result -> robust event
        -> ambiguous/new/invalid -> exact fallback
        -> representation + carrier + placement compiler
             direct electrical
             regional nerve/event spine
             electrical Myelin chord
             optional thin optical Light Nerve
        -> next region / exact computer / output

In parallel:
expired charge -> Charge Artery -> regional shared reservoir -> chip/package recovery
heat -> Thermal Capillary -> shared Thermal Artery/Exhaust -> external collector
```

The exact computer is a precision/fallback/consolidation boundary, not the per-event central router.

## 2. Closed physical front end
### Active-Low Coordinate Release
4-transistor CMOS NOR releases a local region only when row+column selection agrees.

### Regional Event Lease
Validated long selection is reused locally; only validated success/winners refresh it.

Selected 8-way interface:
- 14 NFET + 2 PFET + 1 MIM;
- TT/FF/SS + mismatch closure;
- write + 11 refreshes ~106.8 fJ TT proxy;
- one coordinate selection + lease ~0.787 pJ versus ~5.44 pJ for eight repeated long selections in the earlier communication proxy.

## 3. Local computation primitives
### Capacitive ternary synapses — v12K
Stable local weight structure may be represented physically by MIM coupling; exact residual handles exceptions.

### Shared templates — v12L/v12M
Repeated templates use shared capacitive/static structure rather than repeated memory reads/large one-hot decoding when cheaper.

### Grammar — v12N -> v13A5/A6
Fixed 0.5 V threshold is rejected. Selected robust Grammar uses:
- legal 10-MIM ratio structure;
- 10-MOS dual-input-pair self-check reader;
- fresh replay / two-phase checking where required;
- selected ~6 ns/phase closure;
- TT/FF/SS exact+partial pass;
- combined MIM+MOS mismatch screen with zero wrong accepts in the preserved closure;
- co-placed readout energy roughly 76–97 fJ in the physical battery.

Use Grammar only where motif recognition removes larger work/communication.

### Direct analog steering
If the destination already owns a suitable analog membrane/competition node, local evidence may steer it directly instead of paying a robust reader. Use the robust reader at true boundaries.

### Myelin
- Passive Myelin: short local capacitive structural edge;
- Full-Swing Myelin: robust boundary/event link;
- deep passive analog chains are rejected because separation and absolute level decay;
- stable distant relations may earn direct electrical or optional optical chords.

## 4. Tri-Wall / framework cell
### Tri-Wall Glyph Cell
Three capacitor faces supply local evidence; the fourth side is the preferred connection/service face. Literal vertical sidewall capacitors remain future-process; current SKY130 uses legal planar MIM emulation.

Three ~2x2 um MIM-equivalent walls reproduce ~27 mV-class historical exact/partial separation in the current first-order model.

### Fourth-face neighbor connection
Minimum NFET + small Contact Receptor.
- ~0.5 V analog evidence required ~1.1–1.2 V gate class in tested screens to preserve ~25 mV separation;
- ~0.2 V regional events transfer much more easily.

Existing energy proxies:
- direct neighboring fourth-face event ~0.15 fJ;
- ~180 um event-spine one tap ~0.67 fJ;
- four selected event-spine taps ~1.34 fJ total.

Therefore direct fourth face remains the nearest-neighbor winner; the event spine remains the fanout/non-neighbor layer.

## 5. Autonomic Event Spine — v13D/v13E
Protected shared low-swing trunk with local taps/subwires.

Closed four-tap result:
- ~180 um shielded spine with four isolated branches;
- promoted-tap gate selected at 0.9 V;
- nominal TT/FF/SS pass;
- 12/12 independent TT/FF/SS mismatch launches pass;
- active taps preserve essentially full ~0.2 V event;
- inactive taps microvolt-class;
- protected analog disturbance ~0.344 mV in the existing coupling proxy.

### Familiarity / promotion — v12E
Electrical repetition replaces a digital reuse counter in the fast path:
- first validated use ~1–2 mV familiarity class;
- second ~17 mV;
- third ~28 mV in preserved screens.

Lifecycle:
`validated repetition -> probation -> temporary tap -> slower Use/Lease state -> promoted route`; inactivity demotes it.

### Homeostasis — v12F
Pooled electrical activity increases inhibition/selection pressure when too many weak analog participants load one segment.

### Short electrical context — v12G
Recent charge may directly steer future local competition/inhibition where the margin is sufficient.

## 6. Shared walls and protected service wiring
### Janus / Service Spine Wall
Two cells may share one structural wall. Weak capacitor faces remain isolated; robust services run behind shields.

Selected stack:
`weak face A -> dielectric -> shield -> service lanes -> shield -> dielectric -> weak face B`.

v13C physical proxy:
- unshielded 100 um service line ~1.184 fF coupling to weak face -> ~29 mV simple disturbance -> reject;
- shielded geometry removed direct service-to-evidence capacitance terms at extractor resolution in the tested layout -> keep;
- multiple service lanes require robust signaling, orthogonal routing or additional shields.

## 7. v13K Neurovascular Glyph Cell
Every ordinary cell/cluster is organized like a tiny neurovascular unit rather than sharing one general-purpose service wire.

### Nerve
Fast low-swing event path.
- directly paired neighbor -> fourth-face contact;
- nearby/non-neighbor -> short subwire/Autonomic Event Spine;
- regional fanout -> shared event spine;
- long/hot/reused -> electrical Myelin or optional Light Nerve after break-even.

### Charge Artery
Dedicated low-voltage path for **expired** charge only.
- local reservoir/state performs its original lease/context/familiarity/adaptation job first;
- normal cleanup/expiry opens one-way recovery contact;
- charge moves through a short low-voltage artery into a shared regional reservoir;
- no per-cell converter and no per-cell digital backpressure controller;
- if recovery fails, correctness remains intact and energy may simply be dissipated.

### Thermal Capillary
Passive high-conductivity path from each cell/small cluster toward a shared Thermal Artery/Exhaust. No per-cell pump. Larger/hotter Component Bays receive larger thermal attachments.

### Optional Light Nerve
Only selected long, hot, repeatedly reused relationships receive thin optical/lightpipe routes. It is not mandatory on every cell.

### Exact Service Core
Controller-like exact logic, boot/repair/configuration, memory and exact fallback are shared regionally in Component Bays. Do not duplicate a microcontroller in every cell.

## 8. v13K disturbance solution
v13J3 showed that high-swing facade utilities can consume weak analog margin even when shielded.

Conservative reference:
- weak node ~72 fF;
- useful differential ~25 mV;
- high-margin target ~18 mV;
- coupling proxy ~0.124 fF.

A 1.8 V high-swing line gives ~3.09 mV first-order kick; only about two perfectly aligned transitions fit before crossing the 18 mV high-margin screen.

The v13K Charge Artery uses the actual low-voltage regional recovery class instead. Preserved v13P12 recovery interval: ~0.1990 V -> ~0.2893 V, only ~90.3 mV change.

At the same conservative coupling:
- one 90.3 mV artery transition -> ~0.155 mV kick;
- 8 aligned arteries -> ~1.24 mV total;
- 32 aligned arteries -> ~4.97 mV total, leaving ~20.0 mV from a 25 mV differential;
- about 45 aligned equivalent transitions would be required to cross below the 18 mV screen in the first-order model.

**Decision:** solve ordinary recovery disturbance primarily through voltage-domain and physical-network separation. Facade Quiet Window becomes an exceptional safeguard for high-swing power/config/test activity, not the normal recovery mechanism.

The one unavoidable lifecycle rule remains: do not connect a live information node to recovery.

## 9. Regional energy collection
### v13P12 shared recovery result
One 10 pF recovery reservoir shared across four tiles:
- replaced 40 pF of separate 10 pF reservoirs with 10 pF target -> 75% reduction;
- nominal TT/FF/SS pass;
- 12/12 mismatch launches, 48 tile instances pass;
- weakest post-error second-request remained above the 0.9 V boundary;
- ~220 fJ capacitor-energy increase in one four-tile recovery interval.

The 10 pF reservoir is still a lumped physical candidate, not a closed exterior PEX bank.

### v13K Charge-Artery loading
Using the v13C shielded line proxy ~6.231 fF / 100 um and an illustrative 0.5 mm local branch:
- one branch ~31.16 fF;
- four branches ~124.62 fF;
- branch capacitance ~1.25% of a 10 pF regional reservoir;
- extra energy stored in those four branch capacitances over 0.1990 -> 0.2893 V is ~2.75 fJ versus the ~220 fJ regional stored-energy scale.

For an illustrative 32-cell region, eight 4-cell regional reservoirs give 80 pF target versus 320 pF if each cell owned an independent 10 pF bank, retaining the old 75% shared-capacitance principle.

### Downstream collection
Regional banks are buffers, not permanent batteries. They may drain into a larger chip/package collector where conversion overhead can be amortized. No free-energy claim: each stage can retain only part of what would otherwise be dissipated.

## 10. Thermal architecture
### Cell-level Thermal Capillary
First-order 100 um copper-like conduction model (k=400 W/m/K):
- 5x5 um path -> ~10,000 K/W -> ~1 K rise at 100 uW;
- 10x10 um -> ~2,500 K/W -> ~0.25 K at 100 uW / ~2.5 K at 1 mW;
- 20x20 um -> ~625 K/W -> ~0.625 K at 1 mW.

These are geometry/material calculations, not fabricated GVS thermal results.

### Shared Thermal Artery / Exhaust
Many cell capillaries feed larger hollow vapor/heat-pipe/microfluidic structures and then an external top/package collector.

Sequence:
`cell/component -> passive thermal capillary -> shared thermal artery -> condenser/heat exchanger -> optional large TEG -> outside heat sink/useful-heat loop`.

Cooling has priority over harvesting. Heat is slow environmental physics, not fast route identity.

### Thermal Brake
Replica leak/PVT state may still adjust promotion/retention/inhibition as temperature/process conditions change.

## 11. Hollow / all-surface architecture
### Inside-Out Cell Skin
Cells and support structures may occupy outer, inner, underside and side surfaces if fabrication and total routing/thermal cost justify it.

Illustrative 10x10x2 mm shell with 0.2 mm framework:
- outer area 280 mm^2;
- inner area 245.76 mm^2;
- total inner+outer area 525.76 mm^2 = 1.878x outer alone.

After reserving all-surface area for nerves/arteries/thermal/optical/support:
- 20% reserve -> ~1.50x outer-only usable area;
- 30% reserve -> ~1.31x;
- 40% reserve -> ~1.13x.

These are geometry screens, not transistor-density claims.

### Component Bays
Interior/exterior bays may hold exact logic, SRAM/memory, repair/configuration support, I/O, regulators, recovery support and optical source banks when locality/thermal/manufacturing cost wins.

### Manufacturing grades
**Practical/nearer-term:** active cells on conventional/stacked dies; backside/outer surfaces carry power, recovery, thermal/support; chiplets fill component bays; short 3D bonds emulate fourth-face links.

**Full inside-out:** active cells fabricated on inner/outer/side hollow framework surfaces. This is FUTURE_PROCESS.

Current backside research supports double-sided connectivity, backside power, decoupling and active-functional-backside directions; it does not prove literal active inner cavity walls.

## 12. Facade Utility Shell — retained but simplified
The facade/backside/sidewall remains useful for robust shared infrastructure:
- VDD/GND/reference;
- large recovery/decoupling banks;
- test/repair/ESD/I/O;
- regulators/support devices;
- thermal manifold/condenser;
- optional optical source/coupling bank;
- sparse fault bypass.

Do not duplicate the full nervous network on the facade. Outside wiring did not shorten ordinary cell-to-cell routes in the v13J graph model.

The v13J refined illustrative 32-region recovery routing model gave ~96 mm distributed facade route length versus ~176 mm for a deliberately naive single central collector, ~45.5% shorter; an optimized internal distributed collector could still compete.

### Facade Quiet Window — demoted
High-swing 0.9/1.2/1.8 V facade/config/test transitions may still be staggered or moved outside sensitive analog windows if extracted coupling requires it. This is no longer the normal Charge-Artery control strategy.

## 13. Routing hierarchy
1. direct fourth face — paired nearest neighbor;
2. short Nerve/subwire — nearby non-neighbor;
3. shielded Autonomic Event Spine — regional robust event/fanout;
4. dedicated electrical/Myelin chord — stable short/medium relation;
5. optional thin TIR optical Light Nerve — long/hot/reused route after break-even;
6. contactless capacitive/inductive bridge — tiny assembly gaps only;
7. RF/mmWave — rare broadcast/discovery/backup;
8. exact/global fabric — cold/changing/precise/semantic uncertainty.

## 14. Optional Photonic Layer
Photonics is not default. Thin TIR/direct-photocharge routes are accepted only after distance + reuse + source-idle + manufacturing break-even.

Current conservative v13I expected-lifetime screen:
- 16 uses/relation -> no optical-economic routes;
- 32 uses, 50% hot -> ~8.17% expected communication saving;
- 64 uses, 50% hot -> ~22.34%;
- 128 uses, 50% hot -> ~30.46%;
- 256 uses, 50% hot -> ~34.52%.

At 10 mm / 64 uses / 50% eligibility, preserved whole-workload total improvement was small for image/sound, ~13.97% for code and ~1.40% for reasoning, showing that optics is route-dominated rather than universally useful.

Weak optical analog evidence must be differential/self-referenced, never one absolute light threshold.

## 15. Other physics status
- capacitive contactless coupling: MODE_ONLY for tiny assembly gaps;
- inductive coupling: MODE_ONLY for isolated/vertical gaps;
- RF/mmWave: MODE_ONLY broadcast/backup;
- phononic/acoustic: MODE_ONLY filters/sensors/delay, reject normal routing;
- magnetism/MRAM: FUTURE_PROCESS persistent verified state only;
- MEMS/PCM optical switches: FUTURE_PROCESS rare route consolidation;
- alpha particles: REJECT runtime carrier; KEEP only as radiation-fault model;
- wireless power: reject as default while protected electrical power delivery is cheaper/controlled.

### Radiation Quarantine Rule
One isolated physical spike may not refresh a lease or train persistent structure. Promotion requires repeated validated success.

## 16. Exact computer boundary
Keep exact hardware for:
- arithmetic/carry/index/pointer/code state;
- rapidly changing/cold knowledge;
- close ambiguity;
- semantic invalidation/correction;
- boot/configuration/repair;
- route consolidation verification.

Do not force these functions into analog/optical physics merely for architectural purity.
