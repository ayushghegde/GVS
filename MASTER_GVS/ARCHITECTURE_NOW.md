# Current GVS / Neural Glyph Architecture

## Hybrid division selected by experiments

### Stable / frequent associations
Use physical capacitive/event structure when reuse repays physical area and communication cost:
- capacitive ternary synapses (v12K)
- shared capacitive templates (v12L)
- static binary selector trees (v12M)
- Grammar Cells for repeated local motifs (v12N)
- passive/full-swing Myelin paths for repeated local execution structure (v12Q/R/S)
- promoted fourth-face contacts when repeated validated local use proves the relation is worth keeping (v13B4 candidate)

### Changing / rare / exact knowledge
Use exact digital/computer representation:
- sparse digital residuals for deviations from physical templates
- exact SRAM/table/state where programmability matters
- exact arithmetic, carries, indices, pointers and program state
- exact fallback after ambiguity, invalidity or detected error

### Temporary physical state
Use charge where it replaces repeated metadata/control:
- firing traces / recency / confidence (v12D/E)
- physical leases/hotness (v12P/S)
- short-lived local context/fatigue when useful (v12F/G)
- regional recovery charge (v11V/W -> v13P12)
- fourth-face Use Reservoir for recent validated relation reuse (v13B4 model; transistor integration pending)

### Decision / uncertainty
- local dendrite gathers evidence
- robust soma/competition creates a decision
- multiple survivors/ambiguous state escalates rather than guessing
- winner is regenerated to a full-swing route before analog cleanup
- exact fallback remains independent

## Charge life-cycle rule

Do not treat all leakage/reset charge as either pure waste or free energy.

Selected order:

`live charge -> information`

`controlled leak -> adaptation / timing / threshold`

`expired/reset charge -> one-way recovery when worth the hardware`

This combines the old v11S/T/U self-correction, v11V/W recovery fabric, and v12I recycle/harvest results. Pulling power from a live high-impedance analog state is rejected because it corrupts the information. Recovery happens after capture/expiry.

## Locality rule added by v13A
A physical primitive is not automatically efficient merely because its local event is cheap. The compiler must pay for distance.

Selected topology:

`raw/local evidence -> local Grammar/capacitive/Myelin region -> high-level event/exception -> long fabric`

Rejected topology:

`every feature/synapse/hop -> millimeter-scale global fabric`

At 4x communication stress, v13A required roughly:
- image: >=3 local motif events per long selection
- raw sound: >=3 local events (or one 3-step Grammar motif)
- code: >=2 AST motifs
- reasoning: >=4 hops

At 8x stress, a 12-hop reasoning path should remain almost entirely local.

## Physical communication
The physically extracted GTI direction uses orthogonal long trunks:
- horizontal M4
- vertical M5
- short crossings rather than long parallel runs

This avoids the large coupling seen between long parallel event wires.

For Tri-Wall / framework cells, local communication may instead use:
- a small fourth-face Contact Receptor;
- a promoted static/slow pass contact for a stable relation;
- a sparse direct Myelin chord for a repeated long relation;
- the robust/exact fabric for changing or precise state.

The v13B4 PDK screen shows the existing minimum fourth-face NFET transfers ~25 mV exact/partial separation at a 1.2 V gate across nominal TT/FF/SS. The ~1.0 V Regional-Lease state remains rejected as the direct high-fidelity gate control.

## Self-configuring fourth-face rule

A fourth-face contact may self-promote only from **validated** local success.

Selected candidate flow:

`validated winner -> post-capture residual tap -> local Use Reservoir -> shared PVT/leak threshold -> promote contact`

Raw/noisy events cannot refresh or promote a contact. Inactivity naturally decays the Use Reservoir. While unpromoted or uncertain, the existing robust reader/exact path remains active.

The PVT threshold should be regional/shared, following v11U/v12A:
- two replica leak pilots for an eight-way group;
- one shared slow Environment Reservoir/reference;
- one slow promotion/demotion decision element rather than one powered reader per event.

## Shared-wall framework rule

Structural walls may be shared to reduce duplicated silicon/framework volume, but analog capacitor faces must remain electrically independent.

Selected future wall:

**Janus Service Wall** = `cell-A capacitor face | dielectric | robust central shield/service spine | dielectric | cell-B capacitor face`.

The central spine may combine:
- electrostatic reference/shield;
- ground/reference distribution;
- one-way recovery collection after capture;
- slow pilot/environment routing;
- thermal/mechanical service if later package design supports it.

Do **not** leave the shared midpoint floating by default. The existing physical two-MIM series-pair result (~4.756 fF typical) shows that a floating shared midpoint can create coupling large enough to disturb a ~25 mV local evidence class.

## Regional sharing
Good shared/regional resources so far:
- old v11 regional leak/adaptation sensing;
- two-pilot regional PVT memory from v12A;
- whole-fabric one-way recovery concept;
- current four-tile shared recovery reservoir: 10 pF candidate, replacing four separate 10 pF reservoirs in the tested system screen;
- future candidate: one slow contact trainer/reference for eight fourth-face contacts.

Do not share sensitive local analog competition nodes just to reduce count. Share only resources proven not to corrupt local decisions.

## What an "island" means
An island is not a new AI block replacing Glyph. It is simply a **physical locality boundary**:

- several related Grammar/template/Myelin operations occur nearby;
- the local analog/electrical state does not travel millimeters for every operation;
- one high-level event enters/leaves when needed;
- exact fallback can still access the region.

It is a packaging/layout/compiler concept around already-proven Glyph mechanisms.
