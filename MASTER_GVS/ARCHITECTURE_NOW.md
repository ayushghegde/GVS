# Current GVS / Neural Glyph Architecture

## Hybrid division selected by experiments

### Stable / frequent associations
Use physical capacitive/event structure when reuse repays physical area and communication cost:
- capacitive ternary synapses (v12K)
- shared capacitive templates (v12L)
- static binary selector trees (v12M)
- Grammar Cells for repeated local motifs (v12N)
- passive/full-swing Myelin paths for repeated local execution structure (v12Q/R/S)

### Changing / rare / exact knowledge
Use exact digital/computer representation:
- sparse digital residuals for deviations from physical templates
- exact SRAM/table/state where programmability matters
- exact arithmetic, carries, indices, pointers and program state
- exact fallback after ambiguity, invalidity or detected error

### Temporary physical state
Use charge where it replaces repeated metadata/control:
- firing traces / recency / confidence (v12D/E)
- physical leases/hotness (v12P/S)
- short-lived local context/fatigue when useful (v12F/G)
- regional recovery charge (v11V/W -> v13P12)

### Decision / uncertainty
- local dendrite gathers evidence
- robust soma/competition creates a decision
- multiple survivors/ambiguous state escalates rather than guessing
- winner is regenerated to a full-swing route before analog cleanup
- exact fallback remains independent

## Locality rule added by v13A
A physical primitive is not automatically efficient merely because its local event is cheap. The compiler must pay for distance.

Selected topology:

`raw/local evidence -> local Grammar/capacitive/Myelin region -> high-level event/exception -> long fabric`

Rejected topology:

`every feature/synapse/hop -> millimeter-scale global fabric`

At 4x communication stress, v13A required roughly:
- image: >=3 local motif events per long selection
- raw sound: >=3 local events (or one 3-step Grammar motif)
- code: >=2 AST motifs
- reasoning: >=4 hops

At 8x stress, a 12-hop reasoning path should remain almost entirely local.

## Physical communication
The physically extracted GTI direction uses orthogonal long trunks:
- horizontal M4
- vertical M5
- short crossings rather than long parallel runs

This avoids the large coupling seen between long parallel event wires.

## Regional sharing
Good shared/regional resources so far:
- old v11 regional leak/adaptation sensing (historically useful for natural-firing core)
- whole-fabric one-way recovery concept
- current four-tile shared recovery reservoir: 10 pF candidate, replacing four separate 10 pF reservoirs in the tested system screen

Do not share sensitive local analog competition nodes just to reduce count. Share only resources proven not to corrupt local decisions.

## What an "island" means
An island is not a new AI block replacing Glyph. It is simply a **physical locality boundary**:

- several related Grammar/template/Myelin operations occur nearby;
- the local analog/electrical state does not travel millimeters for every operation;
- one high-level event enters/leaves when needed;
- exact fallback can still access the region.

It is a packaging/layout/compiler concept around already-proven Glyph mechanisms.
