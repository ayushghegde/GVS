# Neural Glyph v14H — Connection Memory Extension

**Status:** v14H2 is a model-level broad intelligence/hardware experiment. It does not claim general AI or fabricated transistor-free hardware.

## Architectural correction
v14H0/v14H1 showed useful exact-operation and need-triggered mechanisms, but intelligence should not be organized around school arithmetic. v14H2 moves persistent semantic memory out of ordinary cells and into sparse learned connections.

### Core rule

`long-term knowledge = connection structure/strength`

`current thought = temporary excitation/charge`

Ordinary semantic cells should not require a dedicated persistent electrical memory state.

## Connection-Imprinted Excitation Fabric (CIEF)
A query excites cue/context cells transiently. Their learned connections deliver weighted charge/evidence to compatible neighbors. Co-firing adds at a receiving node. Goal Echo biases compatible paths reciprocally. Need Potential recruits a reusable structural transformation only when the current state lacks something required by the active goal.

The resulting organization is:

```
input/context excitation
        |
        v
sparse learned connection plane  <---- reciprocal Goal Echo
        |
        v
co-firing / local charge summation
        |
        v
next semantic/intermediate population
        |
        +---- if unresolved ----> Need Potential ----> reusable structural operator
        |
        v
Population Confidence
        |
        v
answer/output transducer
```

## Persistent versus temporary state
Persistent semantic voltage per cell is rejected as the default. Temporary node charge is allowed and necessary while an excitation exists, but it naturally decays/reset between queries.

Sparse specialized state remains allowed where previous evidence justified it: Role Pressure, Local Contradiction Restart/CFN, binding/context windows and recovery buffering are not automatically copied into every semantic cell.

## Connection precision
The current seven-domain model does not repay high-precision analog weights. Two physical levels (weak/strong) remain competitive under substantial modeled variation. Therefore connection precision is a cost knob, not an assumed requirement.

## Redundancy
When a long reasoning path needs robustness, replicate the critical connection or local population rather than adding persistent memory to every cell. Three connection copies gave strong 12-hop robustness in the current abstract stress screen while the overall connection fabric remained extremely sparse versus all-to-all wiring.

## Training modes

### Fixed compiled plane
Weights are converted after training into capacitor/interconnect geometry. No per-link nonvolatile memory device is needed during inference. This may be the cheapest mass-produced inference path but cannot adapt without reprogramming/replacement.

### Plastic two-terminal plane
Only if on-chip learning is required, use a two-terminal nonvolatile connection device. Candidate physics may be capacitive, ferroelectric, resistive or phase-based, but selection is conditional on cost/energy/yield/endurance evidence.

## Role of structural operators
CRRO is kept as evidence that a reusable physical transformation can generalize beyond stored input/output pairs. It is not the architecture's center. Math, code transformation, causal reasoning and planning all enter the same connection fabric; specialized structural operators are recruited only when Need Potential demands them.

## Open problems
1. cheap trainable connection that stores strength structurally rather than as node voltage;
2. long-hop restoration without restoring wrong branches;
3. signed/inhibitory relations using phase/dual-rail or another cheap physical encoding;
4. learning new facts without catastrophic interference;
5. general structural transformations beyond modular addition;
6. stronger confidence/error detection for exact answers.
