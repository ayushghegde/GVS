# Neural Glyph v14Q — Usage-Eligibility Trail Learning

**Status:** model-level extension of v14P. The literal self-electromagnet write mechanism is rejected at nanoscale current levels; the useful retained idea is that ordinary branch use automatically creates a temporary eligibility trace, while confirmation converts eligible use into durable PTC route state.

## Problem being solved

v14P correctly prevents traffic-only learning, but this leaves a useful physical question open: can frequent use make a branch easier to update without allowing frequent mistakes to become permanent knowledge?

v14Q answers yes at the architectural level by separating two states:

- **Eligibility trace:** short-lived, automatically generated by branch activity. It says "this branch was recently involved" and is not trusted knowledge.
- **Persistent trail state:** the v14P Polarized Trail Collar (PTC) state. It changes only after confirmation/contradiction.

## Rejected literal mechanism — self-electromagnet write

A magnet is not electrically positive/negative; it has north/south magnetic poles. Current through a branch does generate a local magnetic field, but the v14O current scale is too small for direct magnetic writing.

Using the v14O model point V=0.25 V and R_ON≈2.3 Mohm gives I≈108.7 nA. For a straight conductor B=mu0*I/(2*pi*r):

- 5 nm: ~4.35 uT
- 10 nm: ~2.17 uT
- 20 nm: ~1.09 uT

At 10 nm, ideal straight-wire current required for:

- 0.1 mT: ~5 uA (~46x current)
- 1 mT: ~50 uA (~460x)
- 10 mT: ~0.5 mA (~4600x)

Therefore v14Q rejects using the ordinary inference current itself as the direct persistent magnetic write field. Adding thousands of effective turns, large write currents, or a per-branch magnetic driver would violate the cost rule.

## New primitive — Usage Eligibility Trace (UET)

**Usage Eligibility Trace (UET):** a temporary local physical state caused automatically by recent branch activity; it modulates later learning sensitivity but does not bias semantic truth by itself.

Candidate physical implementations, simplest first:
1. sub-threshold electric-field/trap occupancy in or beside the existing PTC dielectric;
2. tiny local RC/floating-node history if extracted leakage and area are acceptable;
3. magnetoelectric or magnetic eligibility only if it can be obtained from existing branch terminals without a per-branch driver.

The first candidate is preferred because the branch already has strong local electric fields while its magnetic field is weak.

## Learning rule

1. branch fires -> UET increases temporarily;
2. UET decays if nothing else happens;
3. confirmation arrives -> persistent PTC strengthening is multiplied by recent UET;
4. contradiction arrives -> persistent PTC weakening/reversal is multiplied by recent UET;
5. no confirmation/contradiction -> PTC does not permanently change.

This means repeated successful use can make consolidation faster, while repeated unverified use cannot silently turn into truth.

## Monte Carlo remapping result

Five-way route model, sparse feedback (12% of encounters), route remap during run, identical persistent learning law except for eligibility gain:

- no usage eligibility: mean recovery to >=90% target selection ~242 encounters, median 239;
- eligibility-gated update: mean recovery ~178 encounters, median 177;
- improvement in mean recovery: ~26.3%;
- final 500-encounter accuracy in both cases: ~99.86%.

This is a behavioral/model result, not device proof. It shows that the retained part of the user's idea can speed relearning without reviving traffic-only reinforcement.

## Relationship to v14P

v14P still owns the durable branch preference and guided-gap winner physics. v14Q adds a temporary usage-history state beside it.

Inference path:

semantic excitation -> Choice Node -> guided-gap branch race -> winner

Learning path:

winner use -> temporary UET -> later confirmation/contradiction -> stronger/weaker PTC programming

The UET is never allowed to directly select a route strongly enough to become an uncontrolled second memory.

## Cost rule

Promote a physical UET only if it reuses the existing branch/collar geometry and terminals. Reject it if it requires a transistor, sense amplifier, magnet coil, dedicated write line, or large persistent capacitor per branch.

## Keep / reject

KEEP:
- ordinary use creating a local temporary trace;
- more recent use increasing learning sensitivity;
- confirmation/contradiction gating durable updates;
- v14P PTC as persistent route memory;
- electric/trap implementation as first physical candidate.

REJECT:
- "positive magnet attracts electricity" as the device model;
- direct ordinary-current electromagnet writing at the present branch current;
- traffic-only permanent strengthening;
- expensive per-branch magnetic drivers or coils.
