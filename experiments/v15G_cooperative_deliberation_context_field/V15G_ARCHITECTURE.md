# v15G Architecture

## 1. Temporary partial-thought screen

The screen is a transient optical working surface. Dot voltage is not semantic. The same AI can place an intermediate fragment on the surface as a calibrated brightness pattern held for >=1 us; another region reads that fragment while continuing the same problem.

The selected representation is a normalized analog vector. Static emitter/detector differences are calibrated. A reference dot corrects common drift and a black reference estimates dark background.

## 2. Cooperative deliberation

There is no “answer A, answer B, vote” requirement.

The protocol is:

1. both branches receive the same original prompt/context;
2. branch A writes a partial reasoning contribution into a shared transcript;
3. branch B reads the transcript and adds a missing angle, correction, counterexample, or extension;
4. branch A continues from the updated transcript;
5. alternate until the solution is coherent or the compute/uncertainty condition ends;
6. synthesize once at the end.

The two branches should use independent inference state/sampling so they can explore different continuations. If their trajectories are effectively identical, there is no reason to run the second branch.

## 3. Context Modulation Field

v15G does not encode emotions as commands. It borrows only the broad biological principle that diffuse neuromodulation changes circuit gain and plasticity across many neurons.

Original GVS fields:

- Salience field — changes gain/attention priority.
- Uncertainty field — requests more replay/observation and raises commitment caution.
- Outcome field — signed field that changes subsequent positive/negative dendrite plasticity.
- Urgency field — changes processing-time/energy budget.

These fields never encode “allow”, “block”, “turn left”, etc. Local evidence and learned routes still determine the answer.

## 4. Local memory remains v15D

No extra learning capacitor is added. The existing dendrite/HZO electrode has intrinsic capacitance. Guided-gap firing leaves signed free charge on that node. Repeated use can accumulate charge and gradually consolidate HZO polarization. Unused wrong-path charge leaks away naturally.
