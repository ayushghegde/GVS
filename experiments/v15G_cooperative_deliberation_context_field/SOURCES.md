# External feasibility checks

These sources are used only as physics/behavior sanity checks; no published architecture, text, layout, or code is copied into GVS.

- Mechanisms of neuromodulatory volume transmission, Molecular Psychiatry (2024). Supports the broad principle that diffuse neuromodulatory transmission controls neural-circuit function and behavior.
- Predictive processing and precision / neuromodulation discussion, Frontiers in Psychology (2026). Supports the broad idea that neuromodulatory systems can alter gain/precision, attention, learning and adaptive behavior.
- Wang et al., “Rethinking the Bounds of LLM Reasoning: Are Multi-Agent Discussions the Key?”, ACL 2024. Shows multi-agent discussion is not automatically superior and motivates requiring measured benefit.
- Pitre et al., CONSENSAGENT, Findings of ACL 2025. Identifies sycophancy as a failure mode in multi-agent interaction.
- Bi et al., OPTAGENT, Findings of IJCNLP 2025. Supports interaction quality as an important variable in multi-agent collaboration.
