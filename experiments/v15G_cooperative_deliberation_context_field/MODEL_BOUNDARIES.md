# Model Boundaries

- Optical screen Monte Carlo is a calibrated photon/statistical transport model, not a fabricated optical package measurement.
- v15FG supplies inherited real-ngspice evidence for the detector/power-gate circuit principle. Fresh v15G ngspice was not available in the current runtime.
- Same-model cooperative deliberation is a latent-insight/protocol simulation. It is not a measured GPT-5.6 Sol benchmark because this runtime cannot spawn two independent GPT-5.6 Sol chats.
- Context Modulation Field results are behavioral allocation models. They test the rule “modulate processing, not action identity”; they do not establish subjective emotions.
- Brain literature is used only to support the general plausibility of diffuse neuromodulation controlling gain/plasticity; the GVS field design is original to this experiment.
