# Neural Glyph v13K3 — Integrated Neurovascular Hollow Region

**Verdict: ARCHITECTURE PASS / MANUFACTURING CONDITIONAL.** v13K is a cleaner system than v13J's rule-heavy facade when the recovery network is kept low-voltage and physically separated. Literal active cells on every inner/outer wall remain future-process; the electrical core is still grounded in the existing GVS PDK results.

## 1. Complete region used in this comparison
v13K does not replace the working GVS core. It wraps the existing accepted region:
- Active-Low Coordinate Release;
- eight-way Regional Event Lease;
- physical Grammar/readout path;
- static template path;
- short Passive Myelin + regeneration boundary;
- direct fourth-face relation;
- 0.9 V four-tap event spine;
- v12E familiarity / v12F homeostasis / v12G context;
- shared regional recovery;
- exact fallback.

v13K adds a physical service anatomy to each cell/cluster:
- Nerve;
- Charge Artery;
- Thermal Capillary;
- optional Light Nerve;
- all-surface placement compiler.

## 2. Direct-neighbor rule
For directly touching paired cells, use the fourth-face connection before a subwire.

Existing event-source proxies:
- direct fourth face ~0.15 fJ/event;
- event spine one selected tap ~0.67 fJ/event;
- four selected taps ~1.34 fJ total.

So direct fourth-face communication is ~77.6% lower than paying the one-tap spine for the same private neighboring event in the current proxies. The shared spine still wins when one source fans out to several non-neighbor cells.

## 3. Disturbance comparison
### v13J-style high-swing utility near weak evidence
At the conservative 0.124 fF coupling proxy, a 1.8 V transition injects ~3.09 mV into a 72 fF node. Only about two perfectly aligned transitions fit before a 25 mV differential falls below the 18 mV high-margin screen.

### v13K low-swing Charge Artery
Using the preserved regional-recovery swing ~0.1990 -> 0.2893 V, one artery contributes only ~0.155 mV in the same model. Even 32 aligned arteries leave ~20.0 mV from the original 25 mV.

**Result:** solve ordinary recovery disturbance structurally through low voltage + dedicated routing. Keep timing/quiet-window logic only as a residual safeguard for high-swing exceptional utilities, not as the normal recovery mechanism.

## 4. Recovery cost
For four 0.5 mm Charge Arteries using the v13C shielded-line capacitance proxy:
- total branch C ~124.6 fF;
- only ~1.25% of a 10 pF regional reservoir target;
- extra branch-capacitor energy over the 0.1990 -> 0.2893 V recovery rise ~2.75 fJ;
- preserved regional reservoir energy increase reference ~220 fJ.

Thus the dedicated artery appears cheap enough to justify physical extraction.

## 5. Thermal system
Every tiny cell does **not** receive a pump. Each cell/small cluster receives a passive Thermal Capillary into a much larger shared Thermal Artery/Exhaust. High-power Exact Service Cores, memories and optical source banks receive proportionally larger thermal attachments.

This makes heat collection autonomous: temperature gradients drive heat into the thermal network. The network does not switch electrical nodes and therefore does not need an analog quiet window.

## 6. All-surface utilization
Illustrative 10 x 10 x 2 mm shell with 0.2 mm framework:
- outer area 280 mm^2;
- inner area 245.76 mm^2;
- inner+outer 525.76 mm^2.

After reserving services:
- 20% reserve -> 1.50x outer-only usable area;
- 30% reserve -> 1.31x;
- 40% reserve -> 1.13x.

Therefore placing cells/support on the underside, sides and inner walls can still increase usable surface after substantial nerve/artery/thermal reservation.

## 7. Manufacturing reality
The architecture has two implementation grades.

### v13K practical implementation
- current/stacked active dies hold the local Glyph cells;
- backside/outer surfaces carry power, recovery, decoupling, thermal attachments and selected support devices;
- inner Component Bays use chiplets/memory/exact-control blocks where worthwhile;
- fourth-face/direct links are emulated with short local interconnect/3D bonds.

### v13K full inside-out implementation
- active cells also fabricated on inner/outer/side surfaces of the hollow framework.

The second version is **FUTURE_PROCESS**. Backside-power and active-functional-backside research supports double-sided connectivity and backside devices, but does not prove a literal active hollow cavity wall.

## 8. Optional optics
Optics remains optional, not a fourth mandatory service on every cell.
- short/local: electrical Nerve;
- long/hot/reused: thin lightpipe/optical route only after the existing distance+reuse+source-idle break-even;
- pooled long-range evidence: future Optical Dendrite only when loss of source identity is acceptable.

## 9. Controller/microcontroller question
A normal chip may contain control processors, state machines, SRAM, power-management controllers, DMA/I/O and exact arithmetic blocks. GVS does not need one microcontroller inside every cell.

Selected placement:
- local cell: only the physical mechanisms needed for local work;
- regional Component Bay: shared Exact Service Core / memory / repair/configuration support;
- outside/backside Service Pod: large/hot/slow support if communication cost stays low.

## 11. Decision against v13J
v13J Facade Quiet Window is demoted from a universal recovery rule to a **high-swing exceptional safeguard**.

v13K selected normal behavior:
- firing travels on low-swing Nerves;
- expired charge travels on low-swing Charge Arteries;
- heat travels passively on Thermal Capillaries;
- selected long reuse may travel optically;
- high-swing power/config stays on a separately shielded robust service domain.

This is more decentralized and simpler because physics/geometry prevents most conflicts before scheduling is needed.

## 12. What is not yet solved
- literal all-surface active fabrication;
- physical PEX of one Nerve + Charge Artery + weak node in the same layout;
- physical thermal capillary geometry;
- exact packaging cost/yield for inner/outer active skins.

Those remain the next experiments rather than hidden assumptions.
