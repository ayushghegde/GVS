# Sources / physics sanity checks

These sources are used only to check constituent feasibility or external empirical behavior; v15FG architecture is not copied from them.

- 2025 Optics Letters: micro-LED short-distance optical links demonstrated multi-Gbps communication with measured pJ/bit-scale power. This supports testing microLED scratch communication, not the FSS architecture.
- 2024 Molecular Psychiatry review: neuromodulatory systems can broadly regulate neural circuits, supporting the general feasibility of global gain/bias modulation. This does not imply that v15FG has biological emotions.
- 2026 ACL-SRW multi-agent reasoning study: debate/mixture approaches can improve performance under some compute budgets.
- 2025 systematic multi-agent debate evaluation: debate does not reliably outperform simpler baselines in all settings, motivating optional rather than mandatory self-dialogue.
