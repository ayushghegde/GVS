# v15FG Model Boundaries

- Optical screen test: Monte Carlo photon-count / crosstalk / timing model. Not a fabricated optical package.
- Screen energy: V*I*time emitter-domain proxy plus a simple electrical-bus comparison. Driver, detector, and clock overhead are not fully closed.
- Same-AI dialogue: correlated-error inference model. It is not an actual LLM benchmark because this runtime cannot launch two identical foundation-model sessions.
- Direct modulation: generic decision-task model; it tests functional threshold biasing, not emotion or consciousness.
- Hardware revision request: behavioral persistence detector over synthetic electrical health metrics; physical sensor calibration is not yet included.
- v15D local charge/HZO mechanisms are inherited but not fabricated.
