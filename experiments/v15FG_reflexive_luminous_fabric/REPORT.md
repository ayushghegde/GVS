# Neural Glyph v15FG — Reflexive Luminous Fabric

**Status: PARTIAL PASS — corrected luminous intermediate surface and need-based/reflexive behavior pass the present circuit/statistical models; physical screen/package and real same-model linked-session implementation remain unproven.**

## What happened
The previous v15E interpretation was wrong in two ways. First, the screen is not primarily an optical destination code carrying a whole subproblem. It is an internal analog surface where a specialist places the intermediate value/need it wants another specialist to use. The full question context is already shared by the same AI. Second, same-AI self-discussion is a separate optional execution mode: two same-model sessions get the same prompt, discuss, criticize, and synthesize.

## Screen correction
The example `5*2 -> 10` is represented as logical value 10 on the Science dot for >=1 us. The physical detector remains sub-volt; logical 10 is not literal 10 V on the core. The common power source then activates Science.

300,000-trial optical/noise simulation (±20 analog-unit range):
- hold time: **1.2 us**;
- full-scale optical energy: **80 fJ**;
- full-scale photons: **~237,610**;
- mean decoded scalar error: **0.0235 units**;
- p99 error: **0.0850 units**;
- no false wake or miss observed under the selected crosstalk envelope;
- median crosstalk: **2.00e-4**, p99 **7.19e-4**.

A SciPy transient detector model with 50 fF node capacitance, 30 Mohm leakage, 0.4 A/W responsivity and the 1.2-us optical pulse gives:
- full-scale need-node peak: **0.441 V**;
- at 1 us: **0.389 V**;
- at 2 us: **0.258 V**.

Because the circuit is linear in this operating region, logical value 10 on a ±20/full-scale mapping is approximately half-scale, giving ~**0.195 V at 1 us**.

The screen therefore carries *value + need* while the shared AI context carries semantics.

## Why capacitance still appears
v15D/v15FG do not add a separate capacitor-memory technology. Any small charged electrode has capacitance to its surroundings. The learning state is the positive/negative charge; capacitance merely converts that charge to voltage/field through Q=C*V. The selected local node remains the existing dendrite/HZO electrode.

## Same-AI reflexive mode
A 250,000-task toy evidence model compares one reasoning trajectory against two same-model independent trajectories that exchange confidence-weighted critiques.
- single trajectory accuracy: **94.678%**;
- linked same-AI toy accuracy: **97.994%**;
- gain: **+3.316 percentage points**;
- discussion was needed on ~**19.9%** of trials.

This is only an orchestration model. It does not measure actual ChatGPT quality because this environment does not expose a tool for linking two live ChatGPT sessions.

## Hardware revision request — corrected meaning
120,000 simulated regions with persistent multi-sensor physical faults:
- injected fault fraction: **5.083%**;
- maker-facing revision-request true positive: **99.05%**;
- false positive: **0 observed**.

Unknown knowledge is excluded from this diagnostic. A revision request means the physical chip appears bad.

## Direct emotion-like signals
The system can accept direct signed modulatory fields such as caution/curiosity/urgency. They alter thresholds and verification/replay behavior without hard-coded action scripts.

180,000 generic decision trials:
- baseline unfiltered high-risk action rate: **3.198%**;
- modulated unverified high-risk action rate: **0.171%**;
- verification invoked: **31.39%**;
- additional exploration invoked: **22.97%**.

These are affect-like control signals, not evidence of subjective emotions or consciousness. They can help a goal such as "secure the vehicle" produce context-sensitive verification rather than one fixed alarm rule, but the result still depends on learned world knowledge and reasoning.

## What failed / what is rejected
- literal 5 V/10 V numerical encoding on nanoscale semantic cores is rejected; use safe analog units/charge/intensity calibration;
- screen does not resend the whole prompt;
- hardware-change request is not triggered by a new concept;
- FITA tunnel remains rejected;
- no separate capacitor memory block is reintroduced.

## Remaining problems
1. A real package must show that the dot surface keeps analog value error/crosstalk acceptable for >=1 us over temperature/alignment/scatter.
2. The common-context assumption needs an actual multi-chip state-sharing implementation; otherwise a scalar `10` is ambiguous.
3. Real same-model linked discussion must be benchmarked on language/reasoning tasks; the present toy model only shows why independent trajectories can help.
4. Affect-like direct biases need calibration so they improve adaptive behavior without creating persistent fear/avoidance or unstable feedback.
