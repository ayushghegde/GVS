# Neural Glyph v15FG — Reflexive Luminous Fabric

## Core correction
v15FG separates two mechanisms that were previously mixed together.

1. **Luminous Intermediate Surface (LIS):** a shared internal screen of dots carries a small intermediate result/need signal between specialist chips that already share the same active AI context. It does not transmit the whole prompt.
2. **Reflexive Same-AI Mode (RSAM):** an optional software/execution mode for high-usage users in which two instances of the same AI receive the same prompt, exchange critiques/perspectives, and synthesize one answer. This is not a specialist-chip route and is not a new hardware device.

## LIS
A dot is an analog optical node. Its physical brightness is integrated for at least ~1 us. Dot position identifies which specialist region should receive attention; brightness represents the intermediate scalar/need level.

Example: Math computes an internal intermediate value 10 and Science is needed next. The whole original question is already in shared context. Math therefore lights Science's dot at the analog level representing 10 for >=1 us. The Science-side detector integrates that light and its need node causes the shared package power source to activate Science. Science receives the same question context plus the intermediate value 10.

**Important:** logical value 10 is not literal 10 V on the nanoscale core. A safe sub-volt detector level represents the number 10. Literal 5/10 V core encoding is rejected because it would exceed or strongly complicate low-voltage device limits.

## Local learning remains v15D
- positive/negative dendrite charge is fast state;
- the existing guided gap can charge the dendrite/HZO node during firing;
- when the gap resets, the charge packet is temporarily isolated;
- repeated validated use builds charge and gradually biases/consolidates HZO polarity;
- unused/wrong charge decays naturally;
- no FITA tunnel and no separate memory capacitor are selected.

The word capacitance only describes the unavoidable physical relation Q=C*V of the dendrite/HZO electrode. No extra capacitor memory block is required.

## Need-based thinking
The same recurrent fabric continues without extra consultation when its route is strong. Unknown/conflict/low-confidence states trigger additional replay or specialist consultation. Thinking is a behavior of unresolved state, not a consciousness module.

## Hardware revision request
A maker-facing hardware request is generated only from persistent physical evidence: leakage, timing margin loss, abnormal thermal/power behavior, repeated repair usage, or other measured silicon weakness. Unknown knowledge never by itself means the chip is bad.

## RSAM
When the user explicitly enables it, two same-model instances receive the same prompt and independent reasoning trajectories. They exchange conclusions, criticisms, missing assumptions, and alternatives, then synthesize one response. The purpose is diversity of perspective, not delegation to fixed specialties.

This requires product/software session plumbing; the current experiment only models the orchestration benefit and does not claim a real linked-ChatGPT implementation.

## Direct affect-like modulation
v15FG allows low-dimensional signed bias signals such as caution, curiosity, urgency, or calmness to act directly on thresholds/replay/verification. These are control states, not proof of subjective emotions or consciousness.
