# v14V Idea Ledger

## Retained and actively used
- **Electric polarity:** HZO is the durable learned-route state.
- **Guided volatile gap:** inference/competition event.
- **Field-Isolated Collar (FIC):** HZO and Ag gap interact through electric field, not direct chemistry.
- **Hollow chip:** outer/top surface hosts semantic fabric; dry inner rib surfaces host regional charge reservoirs; backside may host separately isolated cooling/package structures.
- **Electricity harvesting:** charge recovery from regional TEACH/program distribution, not a generator per cell.
- **Repair branches:** spare physical routes retained.
- **Eligibility:** now implemented conceptually as the short-lived ETG state of the already-present passive inhibit layer.
- **Confirmation/contradiction:** one global sign per causal event; corroboration suppresses noisy teaching.
- **Sparse power gain:** only a regional launcher may use active gain.

## New in v14V
- **Activity becomes the address.** A winner branch physically tags itself; the TEACH mesh no longer needs to carry a branch address.
- **ETG — Eligibility Threshold Gate.** A volatile high-conductance state in the passive program barrier opens a short causal learning window.
- **One TEACH mesh.** A single regional program net replaces ordinary row/column learning address rails.

## Rejected in v14V
- normal row/column learning decoder for ordinary learning;
- independently selected row/column write rails for every update;
- per-branch MOS selector;
- standalone eligibility memory;
- permanent learning from mere usage;
- simultaneously broadcasting different feedback signs to different relations;
- claiming passive elements create net power gain;
- claiming patent novelty from this experiment.
