## v15F — Partial-Thought Luminous Screen
The optical surface is **not an address display**. It is a short-lived cross-chip working surface for intermediate fragments of the same question.

Selected first code:
- positive dot bank and negative dot bank;
- each lit dot is driven from a 5-V branch;
- one dot represents 5 units;
- `+10` = two positive dots;
- visible duration >=1 us;
- receiving specialist sees/counts the dots;
- current problem context already determines which specialist is active;
- specialist core always receives its normal supply voltage.

The screen is for small partial results/need magnitudes, not full prompts or arbitrary large tensors.

## v15G — Optional same-model dialogue
This is an application/runtime option, not a silicon neuron. Two contexts receive the same prompt and same model weights, but must have independent inference state/sampling. They exchange compact answers/critiques until agreement/confidence or a cost limit is reached.

If both trajectories are deterministic and identical, dialogue is bypassed because it adds no perspective.

## Direct affect
Affect-like inputs are direct signed modulators on the existing reasoning state: caution, urgency, curiosity/uncertainty. They change evidence thresholds and replay depth. They are not claimed to be subjective feelings and do not encode a fixed action.
