# v14U — Sparse Active Spine

Goal: remove the repeated 8-cell Program Porch by sharing the genuinely active jobs across a 64-cell or larger region while keeping every ordinary semantic cell transistor-free.

Test a passive row/column coincidence network using the existing HZO + nonlinear-inhibit program stack and v14T charge reservoirs. Edge active devices may generate/restore strong program rails, but no MOS may be placed beside a branch or semantic cell.

Acceptance: <=1 shared MOS-equivalent per semantic cell preferred, <=2 maximum unless energy/area evidence strongly justifies more; selected write >= required HZO voltage; half-select disturb below target; regional rail RC within rare-learning latency budget; recovery must reduce total write energy after driver/control overhead; no inference-path MOS added.
