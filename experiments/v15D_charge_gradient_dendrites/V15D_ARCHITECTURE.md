# v15D Architecture — Charge-Gradient Dendritic Fabric

## Core physical path
`axon event → guided volatile gap → many dendritic branches`

Each dendrite carries a signed electrostatic/polarization bias. A more-positive dendrite lowers its effective guided-gap activation barrier, so an electron/current event is preferentially captured there. Exponential nucleation plus shared ballast/quench makes the bias difference decisive.

## Memory in one collar
The existing 4-nm HZO collar is used in two time regimes:
1. **fast free charge:** signed event residue on the local electrode/ionic environment, naturally leaky;
2. **slow HZO polarization:** durable analog preference created after repeated signed charge accumulation.

This replaces FITA and the orthogonal program path.

## Learning rule
- ordinary firing does not automatically mean truth;
- validated/corroborated success leaves positive residue;
- contradiction leaves negative residue;
- uncertain events can remain uncommitted;
- need-based replay happens only when the current path is unknown, close-margin, or wrong;
- repeated residue changes slow HZO polarization automatically;
- after consolidation, free charge is allowed to decay;
- a changed definition repeatedly deposits opposite charge on the obsolete route until its slow polarity is neutralized/reversed.

## Structural rules retained
- ordinary semantic cell: 0 MOS;
- 4 active branches + 2 repair spares;
- guided volatile gap + ballast/quench inference;
- HZO polarity memory;
- dry hollow regional infrastructure / charge-return skin;
- regional active power only, not transistor logic inside semantic branches;
- unknown state is allowed and stays unresolved; hardware revision is requested only for persistent measured physical faults, not merely unknown knowledge.

## Removed from selected v15D
- FITA tunnel anchor;
- orthogonal Ag program path;
- delayed SEEP pocket;
- per-branch HZO selector transistor;
- mandatory 1.2-V row/column program decoder.
