# Neural Glyph v13J2 — Integrated Intelligent Region + Facade + Reservoir + Optional Optics

**Verdict: PASS for the facade/reservoir architecture as infrastructure; CONDITIONAL PASS for optional photonics. The facade/reservoir additions do not materially reduce the core local-compute energy by themselves, but they improve service placement, recovery scalability and fault bypass. Optional optics remains the large runtime-energy lever only for long/hot routes.**

## 1. What is integrated in this screen
The local intelligent block reuses already measured/closed project pieces rather than inventing a new local architecture:
- eight-way Regional Event Lease;
- Grammar/readout structures;
- static template paths;
- short Passive Myelin;
- local robust checkpoints;
- direct fourth-face neighbor link;
- 0.9 V four-tap Autonomic Event Spine;
- v12E familiarity / v12F homeostasis / v12G local context principles;
- exact fallback;
- post-capture charge recovery.

The v13B0 heterogeneous local-region proxy is reused as the local-work reference:
- 3 Grammar readouts;
- 3 static-template events;
- 2 Passive Myelin edges;
- 2 additional robust checkpoints;
- one shared lease;
- ~1459 fJ per such heterogeneous eight-operation region episode versus ~6112 fJ with independent long selections in that earlier proxy.

This remains a system-energy proxy, not a new PDK extraction of all blocks placed together.

## 2. Three architectures compared
### A. v13I Hollow-Electrical Base
All local mechanisms + electrical/Myelin long routes + thermal exhaust. No facade recovery credit in this comparison.

### B. v13J Electrical Facade Architecture
A plus:
- Facade Utility Shell;
- Roof Reservoir Array;
- Hierarchical Reservoir Collector;
- sparse facade bypass.

Runtime data carriers remain electrical.

### C. v13J Heterogeneous Upgrade
B plus the optional thin-TIR/direct-photocharge optical layer for routes that already passed v13I distance+reuse break-even.

## 3. Composite 64-episode stress screen
To combine local and long-route costs in one explicit model, repeat the v13B0 heterogeneous local episode 64 times, then add the v13I 64-use / 50%-hot eight-region communication lifetime model.

Local intelligent work:
`64 * 1.459 pJ = ~93.376 pJ`.

Long-route communication from v13I:
- all-electrical HEB ~86.20 pJ;
- optional heterogeneous HHE ~66.94 pJ.

Hierarchical recovery scenario:
- 64 expired reservoir events;
- local recovered reference ~1.51 fJ each;
- 90% second-stage transfer;
- 10 fJ batch overhead;
- chip-level net recovery credit ~76.98 fJ = 0.07698 pJ.

Composite totals:
- v13I HEB baseline: **~179.576 pJ**;
- v13J HEB + facade + hierarchical recovery: **~179.499 pJ**;
- v13J HHE + facade + hierarchical recovery: **~160.239 pJ**.

Relative to the v13I HEB baseline:
- facade + recovery alone: only **~0.043% dynamic-energy reduction** in this scenario;
- facade + recovery + qualified optional optics: **~10.77% reduction**.

## 4. Interpretation
The facade is not justified by a large per-event energy saving. Its value is:
- moving slow/global utility traffic away from weak analog routing resources;
- providing short access to distributed exterior recovery/decoupling banks on a thin package;
- creating a physically independent bypass path;
- making large support devices easier to share;
- providing natural attachment points for thermal exhaust and optional photonic/source layers.

The reservoir collector is also not a giant energy source. Its recovered energy is small compared with pJ-scale mixed local work, but becomes useful because it is aggregated cheaply and can support low-voltage housekeeping/configuration.

The optional optical layer remains the only large communication-energy improvement in this particular long/hot stress case, and it keeps all v13I break-even/source-idle/manufacturing conditions.

## 5. Outside-versus-inside placement compiler
For every support block, decide placement using:
1. frequency of access;
2. whether signal is weak analog or robust;
3. number of regions sharing it;
4. heat generation;
5. area/volume;
6. fault criticality;
7. route distance/congestion;
8. manufacturing/test cost.

Selected tendency:

`weak + frequent + local -> inside / framework surface`

`robust + shared + slow/large/hot -> wall / facade / exterior if cost wins`

Examples:
- local Grammar/competition/familiarity: inside;
- regional event spine: protected internal/shared wall;
- recovery/decoupling bank: exterior/backside candidate;
- large power regulator: exterior/backside candidate;
- thermal condenser/manifold: exterior/top;
- optional optical source bank: exterior/edge/top where coupling/alignment is easier;
- exact memory/compute: inside Component Bay when locality wins, exterior/package chiplet only when communication and thermal cost justify it.

## 6. Manufacturing consequence
The Facade Utility Shell is not free. It adds backside/sidewall interconnect, vias, exterior passives/support and packaging/test steps.

However, this is a smaller technology jump than mandatory photonics in every package. Backside-power research already demonstrates the physical principle of moving robust utility wiring and decoupling functions to the opposite side of active signal routing.

Therefore the current product hierarchy becomes:
1. **lowest complexity:** v13I Hollow-Electrical Base;
2. **selected v13J default target:** HEB + sparse Facade Utility Shell + hierarchical recovery, if backside/facade packaging proves affordable;
3. **high-route-reuse option:** add Optional Photonic Layer only when its own lifetime break-even passes.

## 7. Failure behavior
The facade bypass is not trained by raw transient activity. If a normal internal robust service route fails:
- exact/health logic marks the route unavailable;
- robust service may use the facade bypass;
- successful replacement familiarity may rise;
- weak analog state is never rerouted onto an uncharacterized exterior path.

## 9. Decision
### KEEP in main architecture
- selective Facade Utility Shell;
- Roof Reservoir Array;
- Hierarchical Reservoir Collector;
- sparse facade bypass;
- inside/outside placement compiler;
- local reservoirs preserved for computation;
- optional photonics remains conditional.

### Do not claim
- facade itself is a major dynamic-energy saver;
- recovered charge powers the whole chip;
- every outside surface should be filled;
- external routing is shorter for ordinary local data;
- the literal hollow/facade package has been physically fabricated in SKY130.
